Why it exists

The space goes where Finder does not look.

A developer Mac fills up in folders you never open.

Xcode keeps build output for every project you have built. Each simulator runtime takes gigabytes. Every repo you clone carries its own node_modules. Gradle, CocoaPods, npm, Homebrew and Docker each keep a cache. And now AI tools add models, chat history and logs on top.

Cleaning it by hand means remembering which folders are safe to wipe and which will cost you an hour of rebuilding. TidyDisk knows these places by name, measures them, and tells you which is which.

A few of the places TidyDisk measures. A cleaner is shown only when its folder, app or tool exists on your Mac.

Why it is free and open source

A disk cleaner asks for deep access to your files. You should be able to read every line of what it does.

So the whole app is on GitHub under the MIT licence. Every folder it measures and every command it runs is in the source, and the list of cleaners is a single Swift file. You do not have to take a cleaner’s word for it: open the code, or build the app yourself.

  • No subscription

    TidyDisk is free. There is nothing to renew and no trial that runs out.

  • No upsell

    No locked buttons and no “upgrade to clean more”. What you see is the whole app.

  • Your files stay on your Mac

    Scanning and cleaning happen locally. No file, file name or path is uploaded anywhere.

What is inside

One window. One tab per job.

Every screenshot on this page is the real app, running on a MacBook Air with a nearly full disk.

Disk

See where the space went.

Developer data gets its own category, so projects, build output, package caches and SDKs do not disappear into “Other”.

  • Four views of one measurement: by location, as a treemap, by folder and by file type.
  • One pass over every file: about 2 million files in under 10 seconds on a MacBook Air.
  • Honest about gaps: folders macOS protects are listed as not measured until you grant Full Disk Access.
Clean

Clean by risk, not by guesswork.

Each cleaner says what it removes and how much it frees before you tick anything.

  • Three risk groups: Safe to clean, Review before cleaning, Handle with care. One button selects the safe group. The other two are never selected for you.
  • Knows developer tools: Xcode, CocoaPods, npm, pnpm and yarn, Gradle, Homebrew, SwiftPM, Docker and simulators.
  • Only what you have: a cleaner appears when its folder, app or tool is on your Mac.
Large Files

Find the files you forgot.

Old disk images, exports and downloads, sorted by size.

  • You pick the size: move the slider and see every file above it.
  • Only files you put there: files inside apps, ~/Library and tool folders are left out.
  • To the Trash: removing a file moves it to the Trash, so you can put it back.
AI

What AI tools cost your Mac.

Claude, ChatGPT, Ollama, LM Studio, Cursor and others, measured in disk, memory and CPU.

  • On disk: models, caches and app data per tool, with the option to remove what you tick.
  • Running now: memory and CPU per AI app, with MCP servers listed on their own.
  • Local servers: which ports are open on this Mac and which process owns each.
Monitor

A system monitor in the same window.

See what is busy before you decide what to close or clean.

  • Live readings: CPU, GPU, memory, disk, network, battery and uptime.
  • Top processes: apps and processes sorted by CPU or by memory.
  • Speed test: a network speed test that runs only when you press Run.

Apps

Uninstall with the leftovers

Each app is listed with the files it keeps in ~/Library. Uninstalling moves the app and those files to the Trash. Leftovers of apps you already removed are found too.

Projects

Build output, per project

Finds your dev projects and clears what they can rebuild: node_modules, build, .dart_tool, Pods, .gradle.

Duplicates

Identical files, found by content

Checks Downloads and Desktop for files with the same content. The newest copy is kept. The rest go to the Trash when you say so.

Menu bar

Free space, always in view

Live free space in the menu bar, a scan in one click, and an optional weekly scan that notifies you when there is something to clear.

Safety model

Nothing is removed until you say so.

Everything a scan finds is sorted into three groups by what it costs to get back.

Safe to clean

Rebuilt by the system or the app when needed.

One button selects this group.

Review before cleaning

Comes back on demand, but downloading or indexing it again takes time.

Never selected for you.

Handle with care

Needs a reinstall before the project runs again.

Never selected for you. Asks once more.

  • Scanning is read-only. A scan only measures sizes.

  • Nothing is ticked for you. One button selects the safe group. The other two groups you tick yourself.

  • Files go to the Trash. What you remove from Large Files, Apps, AI and Duplicates can be put back.

  • Caches and build output are deleted, because the tools that own them regenerate them.

  • Every action is logged. You can read what was done, skipped or failed in the app.

TidyDisk cannot know whether you still need something. Read the list before you clean, and keep backups of anything you cannot replace.

Build it yourself
$git clone https://github.com/prateekcode/tidydisk && cd tidydisk && ./build.sh

build.sh compiles the package and assembles TidyDisk.app in the repo folder. Add --install to copy it to Applications.

Needs macOS 14 and the Swift toolchain that comes with Xcode or the Command Line Tools.

Questions

Short answers.

Is it really free?

Yes. Every feature in TidyDisk 2.0 is free. There is no trial, no subscription and no account. The source is MIT licensed, so you can also read it and build the app yourself.

Is it safe?

Scanning is read-only: it only measures sizes. Nothing is removed until you press Clean. One button selects the Safe to clean group, and the other two groups are never selected for you. Caches and build output are deleted because the tools regenerate them. Files you remove from Large Files, Apps, AI and Duplicates go to the Trash. Every action is logged. TidyDisk cannot know whether you still need something, so read the list before you clean.

Does it need Full Disk Access?

No. It works without it. macOS protects some folders, such as other apps’ containers and cloud storage. Without Full Disk Access TidyDisk leaves those out and tells you so. You can grant it in System Settings, Privacy and Security, if you want them counted.

How is it different from paid cleaners?

It is built for developer machines. It knows Xcode, simulators, Gradle, CocoaPods, npm, Docker and AI tools by name, and uses each tool’s own cleanup command where one exists. There is no subscription, and you can read the source. It does not scan for malware or promise to speed up your Mac.

Where is my data sent?

The app has no account and no ads. It sends nothing unless you switch on anonymous usage statistics in Settings, which are off by default. Features you start yourself, such as the speed test or pushing a project to GitHub, use the network only when you start them.
